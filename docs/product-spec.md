> 版本：v1.0.0
> 平台：Android / Windows / Linux（Capacitor 跨端）
> 用途：产品功能需求规格 + 使用操作说明；供需求评审、Bug 提报与迭代规划使用。
> 反馈方式：基于本文档条目编号（FR-xx / UE-xx）直接指出 Bug 或迭代要求。

## 1. 产品概述

**VaultSec 密码保险库** 是一款本地优先、零云端的密码管理器。所有密码条目以 AES-256-GCM 加密存储在本机，主密码永不落盘、永不上传，解锁全程离线。

- **核心价值**：最高安全等级本地存储 + 双因子解锁 + 跨端可用。
- **目标用户**：注重隐私、需要集中管理多个账号密码的个人用户。
- **安全承诺**：`AES-256-GCM · PBKDF2-600,000 · 主密码永不上传`。

## 2. 核心术语

| 术语 | 含义 |
|---|---|
| 主密码 | 用户创建保险库时设置的唯一凭证，用于派生解密密钥；丢失无法找回 |
| 主密钥 vaultKey | 随机 256 位，仅内存存活，用于加解密全部条目 |
| 双因子 | 解锁需「主密码 + 生物识别」双重验证 |
| 指纹快捷解锁 | 仅凭生物识别即可进入保险库（无需输入主密码） |
| 信封加密 | 主密码派生 KEK 只包装主密钥，条目由主密钥加密 |

## 4. 界面流程

```
应用启动 → init
  ├─ 未初始化 → /setup 创建保险库（步骤1 主密码 → 步骤2 指纹）→ /vault
  ├─ 已锁定   → /unlock 解锁页（主密码 / 指纹快捷解锁 / 双因子）→ /vault
  └─ 已解锁   → /vault 列表
                 ├─ 搜索栏（关键字过滤）
                 ├─ ＋添加密码 → /entry/new
                 ├─ 点条目 → /entry/:id 查看/编辑（删除需确认）
                 └─ ⚙️设置 → /settings
                      ├─ 安全状态 / 指纹管理 / 解锁安全 / 主密码 / 危险区
                      └─ 清空数据 → 回到 /setup
```

## 5. 使用说明（分场景操作）

### 5.1 首次使用（创建保险库）
1. 打开应用 → 进入「创建保险库」。
2. 设置主密码：至少 8 位且强度达到「强」（建议 ≥ 12 位字母+数字+符号混合）。
3. 再次输入确认主密码 → 点「下一步」。
4. （可选）设备支持时开启「录入指纹作为解锁因子」和「指纹快捷解锁」。
5. 点「创建保险库并进入」→ 进入密码列表页。
   > ⚠️ 主密码无法找回，请务必牢记或妥善备份。

### 5.2 解锁进入保险库
- **方式一（主密码）**：输入主密码 → 点「解锁」。
  - 已开启双因子：输入密码后按提示验证指纹。
- **方式二（指纹快捷解锁）**：若已启用，点「指纹快捷解锁」即可直接进入。

### 5.3 管理密码条目
- **添加**：列表页右上「＋ 添加密码」→ 填写名称（必填）等信息 → 点「生成强密码」可自动生成 → 「保存」。
- **查看/编辑**：点击列表条目 → 修改 → 「保存修改」。
- **删除**：条目详情页点「删除」→ 确认后不可恢复。
- **快捷操作**：列表项右侧 👁 显示/隐藏密码，📋 一键复制（到期自动清剪贴板）。

### 5.4 搜索
- 列表顶部输入框输入关键字，实时按名称/用户名/网址过滤。

### 5.5 设置与安全
- **自动锁定**：设置无操作多久后自动锁定；切后台立即锁定。
- **失败销毁**：建议保持开启（默认 10 次），防止暴力破解。
- **修改主密码**：设置 → 主密码 → 修改（需旧密码验证）。
- **清空数据**：设置 → 危险区 → 清空（不可恢复，谨慎使用）。

## 6. 已知行为与边界（评审关注点）

> 以下为当前实现的实际行为，可能包含待确认的设计取舍或潜在 Bug 点，请评审确认。

| 编号 | 行为描述 | 类型 |
|---|---|---|
| KB-1 | 自动锁定仅监听 `pointerdown` / `keydown`，触摸屏点击触发指针事件；纯滚动不触发 touch，长时间滚动可能被判定空闲 | 潜在 Bug |
| KB-2 | 失败销毁触发后直接清空数据库并回到创建页，**无再次确认**，且 destroy 阈值不可逆 | 设计取舍 |
| KB-3 | Web 端（Windows/Linux）复制走 `navigator.clipboard`，非 HTTPS 环境可能回退 `execCommand`，清空剪贴板依赖浏览器权限 | 平台差异 |
| KB-4 | 生成密码固定 20 位、含全部字符集，无长度/字符集选项 | 待迭代 |
| KB-5 | 分类为固定 9 类，不支持自定义分类 | 待迭代 |
| KB-6 | 无条目导入/导出功能，数据仅限本机 | 待迭代 |
| KB-7 | 无「账号锁定后自动解锁倒计时」展示，销毁前仅 3 次才提醒 | 待迭代 |
| KB-8 | 修改主密码时输入框密码强度校验仅在提交时提示，无实时预览（弹窗内仅显示错误） | 体验优化 |
| KB-9 | 锁定态下顶部状态徽标显示依赖 store 状态，切后台再返回时由路由守卫重定向 | 需回归验证 |
